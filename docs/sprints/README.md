# Historial de ejecución de sprints

La carpeta `sprints/` conserva el registro operativo e histórico de cada ciclo de Origen. El roadmap y el alcance base permanecen en [PLAN_DE_SPRINTS.md](../PLAN_DE_SPRINTS.md); cada documento de esta carpeta detalla cómo se ejecutó un sprint y cuál fue su resultado real.

## Uso

1. Crear `SPRINT_NN.md` antes de iniciar el ciclo, usando dos dígitos (`SPRINT_00.md`, `SPRINT_01.md`).
2. Registrar objetivo, capacidad, tareas, responsables, bloqueos, decisiones y evidencia durante la ejecución.
3. Al cerrar, completar el resultado, capacidad real, pendientes y aprendizajes sin reemplazar ni borrar el plan original.

## Qué se conserva al cierre

- objetivo y criterio de cierre, con su resultado alcanzado;
- capacidad planificada y real, trabajo desplazado y causa;
- decisiones, bloqueos, dependencias y evidencia relevante;
- pendientes que pasan al backlog o al sprint siguiente;
- aprendizajes que deban recalibrar el próximo sprint.

Los documentos cerrados son históricos: se agregan aclaraciones de cierre, pero no se reescribe su ejecución para que parezca distinta de lo ocurrido.
